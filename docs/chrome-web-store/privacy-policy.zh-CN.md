# 海报机 PagePoster 隐私政策

生效日期：2026 年 8 月 7 日
最近更新：2026 年 8 月 7 日

本隐私政策适用于 Chrome 扩展「海报机 PagePoster」（以下简称“PagePoster”）。PagePoster 的单一用途是：在用户主动操作后读取当前公开文章，使用用户自行配置的 AI 服务生成中文摘要，并在浏览器中排版为带来源和二维码的分享海报。

## 1. 维护者与联系方式

PagePoster 由 GitHub 用户 `airhunter` 维护。隐私或支持问题可通过以下公开渠道提交：

`https://github.com/airhunter/page-poster/issues`

## 2. PagePoster 处理哪些数据

PagePoster 仅在用户打开扩展并点击“生成海报”后处理当前标签页。可能处理的数据包括：

- 当前公开网页的 URL、规范 URL、来源域名和站点名称；
- 文章标题、网页描述、章节标题和正文；
- 原网页提供的候选文章图片；
- 用户生成的摘要和海报；
- 用户配置的 AI API 地址、API Key、模型名称和海报风格。

PagePoster 不读取或发送 Cookie，不读取浏览历史列表，不处理其他标签页，也不处理本机、局域网或内网页面。

## 3. 数据如何使用

- 文章标题、网页描述、章节标题以及正文开头和结尾各最多约 9,000 个字符，会被发送到用户自行配置的 OpenAI 兼容 AI 服务，用于生成一个核心观点和 2～3 个中文要点。
- API Key 仅作为 Bearer 凭据发送到用户配置的 API origin，用于获取模型列表、测试连接和请求摘要。
- 当前页面 URL 会用于生成返回原文的二维码；来源域名会显示在海报上。
- 候选文章图片可能由扩展在不携带 Cookie、且不发送 Referer 的条件下从原网页或其图片 CDN 获取，仅用于海报排版。
- 所有海报渲染、二维码生成与二维码解码校验都在用户浏览器内完成。

PagePoster 开发者不运营用于接收文章、API Key、摘要或海报的中转服务器。

## 4. 数据共享与第三方服务

文章内容和 API Key 会直接发送给用户主动选择并配置的 AI 服务商。该服务商是独立第三方，其对数据的处理受该服务商自己的条款和隐私政策约束。用户应仅配置自己信任的 HTTPS 服务。

除为实现上述用户请求的摘要功能外，PagePoster 不向第三方出售、出租或共享数据，不将数据用于广告、画像、信用评估、个性化推荐或与扩展单一用途无关的分析。

## 5. 本地存储与保留期限

- API 地址、API Key、模型名称和海报风格保存在 `chrome.storage.local`，不会通过 Chrome 同步。它们会保留到用户清除设置或卸载扩展。
- 当前标签页的文章、摘要和生成状态保存在 `chrome.storage.session`，用于关闭并重新打开弹窗后恢复任务；浏览器会话结束后由 Chrome 清除。
- 用户主动导出的配置 JSON 包含明文 API Key。导出文件的保存、传输和删除完全由用户控制，请仅在可信设备之间使用并妥善保管。
- 复制到系统剪贴板或下载到本地的海报由用户自行管理。

## 6. 数据安全

PagePoster 只应向 HTTPS AI 服务发送用户数据。所有可执行代码均随扩展安装包提供；PagePoster 不下载或执行远程代码。API Key 不会写入源代码、日志、分析系统或开发者服务器。

任何本地浏览器存储都可能受到操作系统账号、恶意软件或其他具有足够权限的软件影响。用户应保护设备账号，并使用可撤销、限额的 API Key。

## 7. 用户控制与删除

用户可以：

- 不点击“生成海报”，从而不触发网页提取或 AI 请求；
- 在设置页更换 API 服务、模型和海报风格；
- 在设置页点击“清除 Key”删除本机保存的 API Key；
- 卸载扩展，删除扩展在 Chrome 中保存的数据；
- 在生成后自行决定是否复制、下载或分享海报；
- 到所选 AI 服务商处行使该服务商提供的数据访问、删除或撤回权利。

## 8. 儿童隐私

PagePoster 不以儿童为目标，也不会主动收集年龄信息。用户不应使用 PagePoster 处理不适合发送给其所选 AI 服务商的敏感内容。

## 9. Chrome Web Store Limited Use

对从浏览器权限获得的信息，PagePoster 的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。相关数据仅用于提供和维护用户可见的单一功能，不用于广告，也不允许人工读取；法律、安全或用户明确请求支持的有限例外，以适用政策和法律为准。

## 10. 政策变更

如果 PagePoster 的数据处理方式发生实质变化，本政策和扩展内相关说明将同步更新；在适用情况下，会在新的处理发生前向用户进行醒目披露并取得同意。
