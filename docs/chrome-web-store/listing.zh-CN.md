# 商店信息（简体中文）

## 基本信息

- 扩展名称：`海报机 PagePoster`
- 简短说明：`一键把公开文章变成带 AI 摘要和二维码的分享海报。`
- 主要语言：`中文（简体）`
- 建议分类：`Workflow & Planning`
- 备选分类：`Art & Design`（如果希望更强调视觉创作）
- 成熟内容：`否`
- 定价：`免费`（模型服务可能由用户选择的服务商另行收费）

简短说明共 26 个字符，低于 Chrome Web Store 的 132 字符上限，并与 `manifest.json` 保持一致。

## 详细说明

把值得分享的文章，变成一张一眼看懂、随手转发的海报。

海报机 PagePoster 会在你主动点击“生成海报”后，读取当前公开文章的标题和正文，调用你自己配置的 OpenAI 兼容 AI 接口生成简体中文摘要，再排成带来源域名和原文二维码的 3:4 PNG 海报。

主要功能：

• 一键提取当前公开文章，不在后台持续读取网页
• 保留原文标题，生成一个核心观点和 2～3 个中文要点
• 内置瑞士编辑、夜间信号、拼贴杂志和东方编辑 4 套版式
• 输出 1080 × 1440 PNG，并在生成后重新解码校验二维码
• 优先复制图片到剪贴板，可直接粘贴到微信、QQ 或文档；复制失败时可下载 PNG
• 同一标签页和 URL 复用已生成结果；“换一版”才会重新请求摘要
• 支持用户自选 OpenAI 兼容 API 地址、API Key 和模型
• 设置保存在本机 Chrome 存储中，不通过 Chrome 同步

如何使用：

1. 安装后打开扩展设置。
2. 填写你信任的 HTTPS OpenAI 兼容 API 地址和 API Key，获取并选择模型。
3. 选择海报风格并测试连接。
4. 打开一篇公开文章，点击工具栏中的海报机，再点击“生成海报”。
5. 复制海报，或在复制不可用时下载 PNG。

隐私与数据说明：

只有你主动生成时，扩展才会处理当前页面。为生成摘要，文章标题、网页描述、章节标题以及正文开头和结尾各最多约 9,000 个字符会发送到你配置的 AI 服务商；PagePoster 开发者不运营中转服务器，也不会接收这些内容。API Key 保存在本机 Chrome 存储中，并仅用于访问你配置的 API 地址。请仅配置你信任的 HTTPS 服务，并同时查看该服务商自己的隐私政策。

当前限制：

• 不支持 PDF、本机/局域网/内网页面、付费墙和必须登录后才能读取的正文
• 不适合社交信息流、复杂 Web App、iframe 正文、视频或播客
• 不提供模型或 API 额度，需要用户自行准备兼容服务
• AI 摘要可能有误，分享前请核对内容；二维码始终指向原文页面

PagePoster 不投放广告，不出售数据，不收集分析数据，也不加载或执行远程代码。

## 分发建议

- 首次审核：`Unlisted`，先用真实商店安装包完成一次端到端验证。
- 验证通过后：切换为 `Public`。
- 地区：`All regions`。当前界面为简体中文，商店主要语言应保持为中文（简体）。
- 官方网址：如果已通过 Google Search Console 验证自有域名，再填写；没有自有域名时不要冒充已验证网址。
