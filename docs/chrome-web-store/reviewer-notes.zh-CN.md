# 审核人员说明

## 可复制版本

海报机 PagePoster 的单一用途是：在用户主动点击后读取当前公开文章，调用用户自行配置的 OpenAI 兼容 AI 服务生成中文摘要，并在浏览器本地排版为带来源域名和原文二维码的 1080 × 1440 PNG 海报。

测试步骤：

1. 安装扩展后，右键工具栏图标或从扩展管理页打开“选项”。
2. 填写随审核提交材料单独提供的 HTTPS API Base URL 和临时 API Key。
3. 点击“获取模型”，选择随凭据说明提供的模型；点击“测试连接”，确认成功后保存。
4. 打开一篇无需登录即可阅读、正文不少于约 500 字符的公开 HTTP(S) 文章。
5. 点击工具栏中的海报机，再点击“生成海报”。
6. 生成完成后检查标题、中文摘要、来源域名和二维码；点击“复制海报”。如果运行环境不允许写入图片剪贴板，界面会显示“下载 PNG”作为后备方式。
7. 点击“换一版”可以在复用已提取文章的前提下重新生成摘要。

权限说明：

- `activeTab` + `scripting`：只在用户点击生成后，向当前标签页注入随包提供的正文提取器。
- `storage`：本机保存 API 配置和海报风格；浏览器会话内恢复生成状态。
- `clipboardWrite`：只在用户点击“复制海报”后写入生成的 PNG。
- 可选 HTTPS 主机权限：只在用户保存/测试配置时，请求其填写的单个 AI API origin；更换地址后移除旧权限。

数据流：

- 发送给用户所选 AI 服务：文章标题、网页描述、章节标题、正文开头和结尾各最多约 9,000 字符。
- 不发送：Cookie、浏览器历史列表、完整 HTML、其他标签页内容。
- API Key 与文章内容不经过 PagePoster 开发者服务器；本项目没有分析、广告或遥测服务。
- 所有 JavaScript 都随扩展打包；AI 响应作为 JSON 文本解析，不执行远程代码。

不支持的页面：PDF、本机/局域网/内网页面、付费墙、需要登录才能读取的正文、社交信息流和复杂 Web App。

## 审核凭据交付提醒

请在 Chrome Web Store 的受保护审核凭据字段中提供以下内容，不要写进此仓库、商店公开说明或截图：

- HTTPS API Base URL
- 可撤销、限额的临时 API Key
- 可用模型名
- 凭据有效期与必要的地区限制

审核完成后撤销临时 Key。
